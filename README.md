# travel-booking-management-system

A C# Windows Forms desktop application for managing travel trips, users, and reservations.

## Functionalities

### Authentication

- Register new users
- Sign in as an administrator or client

### Admin Panel

- Add, edit, remove, and view users
- Add, edit, remove, and view travel trips
- Add, edit, remove, and view reservations

### Client Panel

- Browse available trips
- Book a trip
- Edit or cancel reservations

## Technologies

- C#
- Windows Forms
- .NET Framework 4.7.2
- XML Serialization for local data storage
- Visual Studio

## How to Run

1. Open `project.sln` in Visual Studio.
2. Build and run the project with `F5`.

The application creates XML files locally to store users, trips, and reservations.
